# 实验3 v3：跨维诊断驱动的策略选择与变化信息保留

日期：2026-10-21。状态：实验设计稿，未训练选择器，未计算新策略的正式表现。

本轮按作者选择，以现有土地覆盖产品检验策略选择和处理保真度。拟替换当前4.5.4的主要证据组织方式；原实验、失败结果、Word稿及计算输出全部保留。本方案提出一个新的、可执行的框架实现，不能将尚未执行的设计写成已有结果。

## 1. 要检验的命题

在相同输入、空间支持域和输出表达容量下，依据少量诊断区域的空间、语义与跨期关系特征选择处理策略，能否比一贯使用开发阶段最佳固定策略，更好地保留新样区的SL变化位置？

核心变化是把“框架”落实为一个在评价前作出选择的规则。它可以选对，也可以选错；效果在没有用于选择的区域上计算，因此改善不是面积守恒或复用原生图带来的必然结果。

主要终点：2010—2020年、30×30支持域、SL变化并集的面积加权F1。主要效应为“框架选择器减最佳固定策略”的F1差。扩张与收缩分项、3×3与10×10为预定补充，不替换主终点。

拟检验的结论分两层：

- 选择价值：逐样区选择是否优于最佳固定策略。
- 诊断增量：跨维诊断是否优于使用同一学习方法、但只使用单期组成与空间复杂度的选择器。

选择价值为主问题，诊断增量决定能否进一步归因于框架中的跨维诊断。仅第一层成立时，只支持本实现的自适应选择价值。

## 3. 数据与空间划分

输入沿用Han2000、2010、2015、2020及Wang2020的合法类别交集作为共同有效域。任务分类只用Han2010与Han2020；另外三份输入仅参与共同有效域构建。语义映射维持SD=1、SL=21—24、Others=3。

候选池沿用已完整记录的714个合格窗口，窗口大小1200×1200原生像元，涵盖全部熵分布，不只取High/Low两端。结论范围为这一混合SL候选池及新划分条件，不把它称为全部蒙古高原的随机代表样本。

### 3.1 已完成的几何可行性检查

检查仅读取候选CSV、旧24窗位置和冻结参数中的B2位置，没有读取原始栅格或新策略表现。

- 距旧24窗及B2中心至少100 km的合格窗口有423个。
- 以EPSG:6933投影、原点(0,0)、200000 m边长构建分区，排除含旧窗口的分区后，余258个合格窗口。
- 其中22个分区可以各选两个中心间距至少50 km的窗口。
- 按种子20261021的固定几何规则，可以保留20个测试分区、40个测试窗口，并另选36个开发窗口。
- 开发集为原24窗＋新36窗，共60窗；B2不参与训练或测试。

名单见“空间划分可行性_候选名单.csv”。它是本设计的候选划分，当前未冻结，不含按实验效果选区。

### 3.2 划分规则

测试窗口所在分区不进入开发集。测试与全部开发窗口的中心测地距离至少100 km；新选窗口之间采用至少50 km的中心距离约束。200 km是投影坐标下的分区边长，100/50 km按WGS84测地距离计算。

测试分区随机排序；每区从符合距离条件的窗口对中均匀抽取一对。因几何约束无法选取时，只按事先固定的下一分区顺延，并记录原因。开发新增窗口在剩余合格位置中按最大最小中心距离选取。以上规则在计算新表现前冻结。

正式统计以20个测试空间分区为重采样单位，每区两个窗口先等权平均。不能把40窗×3尺度×5策略作为600个独立样本。

## 4. 统一输出，建立五个合理候选策略

每条路径接收同样的两期原生分类与共同有效域。在相同支持域下，最终每个粗格仅输出一个uint8方向码：0=SL成员关系未变，1=扩张，2=收缩，255=未确定。粗格展开后只在共同有效像元评价。

原生图和比例图可以作为计算中的临时量，但不作为隐藏输出保留。所有策略的码表、网格、有效mask、地理信息和必要元数据一致；同窗同尺度的最终栅格数组容量相同。

| 编号 | 候选路径 | 具体操作 |
| --- | --- | --- |
| S1 | 空间优先 | 两期分别在六细类中取面积优势类，映射到SD/SL/Others，再形成SL方向变化码 |
| S2 | 语义优先 | 两期先把四个SL细类合并，再分别取三类面积优势，形成SL方向变化码 |
| S3 | 跨期转移优先 | 原生像元先映射到三类，形成九种有向转移；粗格选面积最大的转移，再映射为SL方向码 |
| S4 | 目标事件优先 | 原生像元先形成SL未变/扩张/收缩三类事件，粗格选面积最大的事件 |
| S5 | 开发阶段校准的事件阈值 | 原生SL扩张、收缩面积比例之和达到固定阈值τ时判为变化，方向取二者面积较大者；否则判为未变 |

S5的τ只从{0.05,0.10,…,0.95}中选取，以开发数据主任务F1均值确定。开发交叉验证中，τ必须在每个训练折重新确定；测试时使用开发集最后冻结的τ，不按测试窗调整。并列最优τ取较大值。这个候选用于避免只与未经任务校准的众数方案比较。

面积优势并列的容差沿用“最大与次大面积差≤有效总面积×10⁻¹⁰”。S3先按九类判并列，不能在知道其方向后选择性解除并列。S5达到变化阈值但扩张与收缩面积在同一容差内并列时输出255；不发生变化时输出0。无有效面积的格均为255。

S4按定义优化格内三事件的0—1一致面积，其对应准确率只作性质核查。主指标F1并不由该逐格众数最大化，因此不能预定S4或其他候选获胜。

## 5. 有限诊断区与独立评价区

### 5.1 固定诊断预算

主尺度30×30对应40×40个粗格。将窗口分成5×5个空间层，每层含8×8个30像元粗格。每层从正有效面积粗格中随机抽取2格，共最多50格，即整个窗口原生像元的3.125%。不足2格时取全部，不从其他层事后补充。

诊断样本只依据位置、共同有效mask和固定种子生成，不依据变化、熵或任何策略的误差。每窗种子由20261021和稳定窗口ID的SHA256派生，不使用Python随机hash。

评价区域排除诊断格及其周围一圈30像元粗格；缓冲只影响评价区域，不向选择器开放其中标签。所有方法采用相同诊断mask、缓冲mask和评价mask。3×3与10×10补充分析继续使用这套原生位置划分，避免把诊断点重新计入评价。

分层抽样时，每个粗格的纳入概率为本层抽取数/本层合格格数。需要估计窗口组成或试运行混淆面积的量使用面积权重与纳入概率倒数；非线性F1采用相应估计混淆量的比值。

### 5.2 选择模块的访问边界

选择模块可以读取：固定任务、尺度、网格与编码定义、共同有效mask、诊断格内两期分类，以及开发集训练好的模型。

选择模块不得读取：测试评价区域原生事件图、任何候选在该区域的TP/FP/FN/F1、完整变化比例场、事后最优策略、High/Low标签或窗口坐标作为模型特征。坐标仅用于划分，不用于记忆样区。

正常候选算法执行时需要读取两期完整输入；这不等于允许选择器计算全窗参考误差。接口上分离诊断、选择、执行与评价。先保存选中策略及哈希，再生成测试评价结果。选择器使用当前两期输入的小范围诊断，不预测未来变化。

## 6. 将框架落实为可检验的选择规则

采用一个浅层多输出回归树作为可审计的选择器，不以提出新的机器学习模型为论文贡献。树预测五个候选在独立评价区域的F1，选择预测值最高的一项。

固定模型容量：最大深度2、每叶至少8个开发窗口，平方误差准则，固定随机种子。模型结构不因测试结果改变。预测并列容差10⁻¹²，按S2、S5、S1、S3、S4的预设顺序选取。

### 6.1 输入诊断特征

| 特征组 | 诊断量 | 与框架的关系 |
| --- | --- | --- |
| 基础特征6项 | 两期SL面积比例；两期三类熵的平均值；两期最大类别比例的平均值；两期类别边界密度的平均值；诊断区有效覆盖率 | 单期组成及空间复杂度 |
| 跨维特征5项 | SL内部细类条件熵；两种语义/空间顺序的分歧率；九类转移分布与两期边际乘积分布的总变差距离；SL变化面积比例；扩张与收缩的抵消程度 | 语义合并、操作非交换性与跨期配对关系 |

跨维特征均来自诊断区。条件熵对两期按SL有效面积加权汇总；顺序分歧率对两期共同可判定的诊断粗格汇总。转移总变差为0.5×Σ|p_ij−p_i·p_·j|，在诊断格计算后按有效面积汇总。抵消程度为1−|E−C|/(E+C)，E、C为诊断区估计扩张/收缩面积；E+C=0时设为0并标记无事件。边界密度为诊断格内部、两端均有效的四邻接像元对中异类对的比例，跨格边界不计。

无法定义的特征保留缺失标记，以训练折中位数填补；变换参数只拟合训练折。全部诊断特征不可用时退回开发阶段最佳固定策略。无SL等状态不能直接解释为低风险。

### 6.2 与五环节的实际对应

| 环节 | 本版实际发生的操作 |
| --- | --- |
| 任务定义 | 固定SL变化位置、F1、输出网格及诊断预算 |
| 失配诊断 | 从诊断格测量组成、边界、语义合并分歧及跨期关系 |
| 跨维约束 | 统一有效域、编码与输出容量；禁止评价区信息进入选择 |
| 策略组织 | 冻结的树根据诊断量选择S1—S5中的一个 |
| 结果验证 | 在未参与选择的区域计算保真度，并记录选择成功或失败 |

本次重点验证“诊断→选择→任务收益”。若没有实际迭代，不把最终验证写成已经执行的迭代优化。

## 7. 对照方法：既比较固定策略，也比较简单选择器

| 方法 | 规则 | 回答的问题 |
| --- | --- | --- |
| B0 常规固定S2 | 所有样区使用语义优先路径 | 提供熟悉的流程参照 |
| B1 最佳固定策略（主要对照） | 在开发集确定平均F1最高的一个候选，测试窗全部使用它 | 自适应选择是否优于一个强固定方案 |
| B2 基础诊断选择器 | 与框架使用相同模型容量、训练数据和候选池，只使用6项基础特征 | 跨维诊断是否提供额外信息 |
| B3 小样本直接试选 | 在相同诊断格上执行全部候选，按估计F1最高者选取；诊断区无参考变化时退回B1 | 完整选择器是否优于简单试运行 |
| F 框架选择器 | 使用完整11项诊断特征的冻结选择器 | 待验证实现 |
| Oracle 事后最优 | 评价后才确定每窗实际最优候选 | 测量候选池存在多大选择空间，仅作上限参照 |

B1的候选编号与S5阈值全部在开发集冻结，禁止按测试平均成绩换成另一个“最佳固定”。同时可以报告测试集事后最佳固定策略作为描述性参照，但明确它不可用于真实选择。

B2与F共享模型类别和容量，不用“规则法对复杂学习器”制造算法能力差。B3拥有同一诊断预算，防止把“允许少量试运行”的收益全部归给框架概念。

## 8. 开发、冻结与一次性测试流程

1. 冻结空间名单、候选集合、诊断和评价mask生成规则、主要指标及分析规则。现有可行性名单不得根据新策略表现调整。
2. 在60个开发窗上产生五个候选的输出与诊断特征。主任务监督值来自各窗评价区域，不使用诊断区作为模型拟合目标。
3. 采用5折空间分组交叉验证考察开发阶段表现。同一空间分区的全部窗口及各尺度放在同一折，训练折剔除距验证窗中心100 km以内的窗口。每折的S5阈值、缺失填补、B1和两个树均只用训练折拟合；验证折只用于开发报告。本版树容量固定，不根据最有利折继续改深度。
4. 报告开发集的候选表现差异和oracle与最佳固定之间的间距。没有选择空间时如实说明，不删除表现相同的样区，也不替换主尺度。不存在“区分度不足就不报告”的测试门槛。
5. 用全部开发数据拟合最终S5、B1、B2及F，保存模型、特征表、代码和文件哈希。正式测试前固定所有参数。
6. 对40个新测试窗，只开放诊断区，保存每个选择器的策略编号、预测得分、命中叶节点及选择理由。
7. 冻结选择后，评估器计算各候选在评价区的表现。所有反事实候选只为评价和oracle计算运行，不向选择模块回传。
8. 完整报告全部窗口、未确定输出、无变化窗口和失败记录。测试后修改规则须另记新版本，不能覆盖本次结果。

各尺度分别计算诊断特征并拟合相同容量的选择器；三个尺度的同一窗口始终属于同一空间折，不能互相充当训练与验证样本。开发监督目标仅使用参考变化面积为正的窗口；无变化开发窗保留为误报诊断。某折可用训练窗不足16时，该折选择器退回该折B1并记录，不能删除困难验证折。

开发阶段若需要客观代码修复，保留修复记录并重算受影响结果。若改变科学设计，必须在测试结果开放前重写版本说明。

## 9. 指标、成本与判断标准

### 9.1 主要任务指标

TP_A、FP_A、FN_A为评价区域内有效面积，F1=2TP_A/(2TP_A+FP_A+FN_A)。未确定预测上的参考变化计入FN_A，覆盖率另报。参考变化面积为正时各候选均有定义；参考变化面积为零的窗口不进入主要F1估计，但统一报告假变化面积和可判定覆盖，不补样，不对不同方法采用不同删窗规则。

主要差值：Δ_w=F1_F,w−F1_B1,w。先在每个测试空间分区内对有效窗口差值等权平均，再对空间分区等权平均，明确为本次测试设计下的平均收益。

### 9.2 选择质量

Regret_w=max_s F1_s,w−F1_selected,w，越小表示选择越接近事后最优。事后最优只在所有预测与选择被冻结后计算。报告每窗regret、被选策略频数、近似最优选择率（与最优差≤0.01）及平均正/负收益。

F1收益与regret降低源自同一张表现表，不能把两者当作两份独立显著性证据。阈值0.01是本设计的报告约定，不是领域通用标准。

### 9.3 统计与实际意义

主要报告20个空间分区的配对差，以及10000次整空间分区bootstrap的95%百分位区间。尺度、候选和同区窗口一起保留在重采样单元内；不同统计量采用独立派生随机流，避免旧脚本的随机数消费耦合。

预设最小实际收益δ=0.02，即F1绝对提高2个百分点。这是规划用的实际意义阈值，不是已有实验结果或普遍规范。主要证据判断为：平均差达到δ，且主要95%区间下限大于0。区间下限若也高于δ，才可说“至少达到该幅度”的证据更强。

20个空间分区不自动保证足够统计功效。开发阶段用空间分组差值的变异估计预期区间宽度；若样本量不足，只能在测试开放前扩充独立空间覆盖或明确降低为探索性结论。不得看测试显著性后追加窗口直到显著。

F−B2和F−B3为预定次要比较，完整报告效应及区间，不用某项较有利结果替换F−B1。若要对它们作同时成立的正式推断，另报告针对两项比较的97.5%区间；不以若干未校正95%区间挑选成功结论。

### 9.4 次要任务指标与成本

报告扩张F1、收缩F1、IoU、FP/FN面积、可判定覆盖率及零事件情形。30×30是唯一主尺度，3×3和10×10按同一流程作完整补充分析。

记录诊断读取像元数、候选试运行耗时、特征提取和选择耗时、最终路径执行耗时、峰值内存、输出逻辑字节及压缩字节。模型文件、诊断mask/索引及重现选择所需元数据单列并计入端到端存储；共同部分对每方法按同一口径计算。评估器事后跑全部候选的成本与实际选择成本分开。

本版控制相同粗格输出表达容量，不宣称端到端计算成本完全相同。若收益伴随较大诊断开销，需同时给出代价，不能只报告F1。

## 10. 什么结果支持什么结论

| 观察结果 | 可以支持的判断 |
| --- | --- |
| F优于B1，且达到预设实际意义 | 本实现对新空间样区的逐样区策略选择有效 |
| F同时优于B2 | 跨维诊断比单期组成与空间复杂度提供了额外选择价值 |
| F同时优于B3 | 本选择规则优于同诊断预算的简单直接试选 |
| F优于B1但不优于B2/B3 | 自适应选择有收益，但不能把收益特指为完整跨维诊断框架的独有优势 |
| Oracle明显优于B1，F却没有优势 | 候选池存在选择空间，但当前诊断或选择规则没有利用好 |
| Oracle与B1接近 | 该条件下固定策略已足够，不能靠继续换选择器保证获得收益 |
| 某一候选始终最优 | 支持使用该固定策略，不能将它重新命名为“自适应框架优势” |
| 收益只出现在补充尺度 | 如实报告尺度依赖，主条件仍按原计划判定 |

整个实验检验本方案的具体实现和候选池，不证明抽象五环节所有实现均有效。源产品为内部参照，结论是信息保留，不是地表真实性提升。

## 13. 方法依据与引用范围

按实例特征在候选算法中选择，是已有算法选择研究的基本问题；本方案采用这一可检验形式来落实框架的“诊断—选择”关系，不把一般算法选择思想声称为本文首创。[Kerschke等的作者版本](https://arxiv.org/abs/1811.11597)

模型选择、预处理和阈值确定须限制在训练数据中，不能以参与选择的数据评价最终收益；开发阶段的折内完整重拟合据此安排。[Varma与Simon，2006](https://link.springer.com/article/10.1186/1471-2105-7-91)

地理数据的评价需要考虑空间依赖，采用空间分组的训练和评价；分块尺度也会改变外推难度，不能仅凭固定缓冲宣称完全独立。[Roberts等，2017，作者机构全文](https://www.wsl.ch/lud/biodiversity_events/papers/Roberts_et_al-2017-Ecography.pdf)

以上用于支持设计原则，不用于预言本实验结果。原论文参考文献编号本轮未修改。
